# Exercise 0.6: New Note in Single Page App Diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User inputs a note and submits the form
    Note over browser: JS handler prevents default form reload (e.preventDefault())
    Note over browser: JS appends the note locally and re-renders the DOM immediately

    browser->>server: POST [https://studies.cs.helsinki.fi/exampleapp/new_note_spa](https://studies.cs.helsinki.fi/exampleapp/new_note_spa)
    activate server
    Note over browser: Payload: { "content": "Single Page App note", "date": "2026-09-16..." }
    server-->>browser: HTTP 201 Created ({"message":"note created"})
    deactivate server
```
